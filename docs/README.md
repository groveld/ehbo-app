## Herkomst

Ontwerp gemaakt met Claude op 28 oktober 2026. De oorspronkelijke versies staan ook online (privé, account Martin):

- Functioneel ontwerp: https://claude.ai/artifact/9kPLdEtjhEQidDnbRnipmU
- Schermontwerp: https://claude.ai/artifact/VK6w9wwvti59R6Pu57nGKZ

De bestanden in deze map zijn de bron van waarheid. Pas je iets aan in de online versie, exporteer het dan opnieuw hierheen (of andersom), zodat beide gelijk blijven.
